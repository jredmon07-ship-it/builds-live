# builds-live

Static hosting for two **sample/spec** portfolio builds. Neither is a real company —
both are fictional showcase brands, labeled as such throughout their own pages.

- `hale-group/` — The Hale Group, a sample luxury brokerage brand
- `halden-watch/` — Halden Watch Co., a sample watchmaker concept

Served by GitHub Pages from the repo root. `.nojekyll` is required: Jekyll would
otherwise ignore every path beginning with `_`.
